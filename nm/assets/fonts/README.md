Self-hosted Latin subsets, all under the SIL Open Font License 1.1:
**Geist** (variable 300–600, text), **Geist Mono** (variable 400–600, prices
and labels), **Bricolage Grotesque** (variable 500–800 at optical size 96,
display headings) and **Newsreader** italic (optical size 72, the emphasised
word in each heading). Thai (Noto Sans Thai) and Arabic (IBM Plex Sans
Arabic) are loaded from Google Fonts only when those languages are selected
(see `assets/js/i18n.js`).
