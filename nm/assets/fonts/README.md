Self-hosted fonts:

- **Satoshi** 500 / 700 / 900 (display headings, buttons) — Indian Type
  Foundry via Fontshare, free for personal and commercial use (ITF Free
  Font License).
- **Fraunces** italic (optical size 72, the gold key word in each heading)
  and **Inter** (variable 400–700, body text) — Latin subsets, SIL Open Font
  License 1.1.

Thai (Noto Sans Thai) and Arabic (IBM Plex Sans Arabic) are loaded from
Google Fonts only when those languages are selected (see `assets/js/i18n.js`).
