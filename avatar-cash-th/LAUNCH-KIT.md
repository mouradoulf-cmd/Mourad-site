# Avatar Cash TH — คู่มือเปิดขายให้ได้เงินจริง

## ✅ สิ่งที่ "พร้อมใช้งานแล้ว" ในเว็บ
- หน้าขาย `index.html` (SEO, OG, ตารางเปรียบเทียบ, โบนัส, การันตีคืนเงิน, FAQ)
- **ชำระเงินจริง** `checkout.html`: QR พร้อมเพย์แบบใส่ยอดอัตโนมัติ (มาตรฐาน Thai QR, ตรวจ CRC แล้ว) + ปุ่มส่งสลิปทาง LINE + ปุ่มบัตร (เมื่อใส่ลิงก์ Stripe)
- ของแจกฟรี `free.html` (พรอมต์ 20 ข้อ + ปุ่มบันทึกเป็น PDF) — เก็บ Lead
- ห้องเรียน `members.html` (5 โมดูล + แถบความคืบหน้า)
- หน้ากฎหมาย `terms.html` (คืนเงิน 7 วัน) `privacy.html` (PDPA)

## 🔧 ตั้งค่า 10 นาที (ไฟล์ `assets/js/main.js` บล็อก CONFIG บนสุด)
| ค่า | ทำอย่างไร |
|---|---|
| `LINE_OA` | สมัคร LINE Official Account (ฟรี) ที่ manager.line.biz แล้วใส่ `@ชื่อ` |
| `PROMPTPAY` | เบอร์พร้อมเพย์ของคุณ → QR จะโอนเข้าบัญชีคุณโดยตรง ไม่มีค่าธรรมเนียมแพลตฟอร์ม |
| `ACCOUNT_NAME` | ชื่อบัญชี |
| `MEMBER_CODE` | รหัสเข้าห้องเรียน เปลี่ยนเป็นของคุณ |
| `STRIPE.life/month` | (ไม่บังคับ) สร้าง Payment Link ใน Stripe รับบัตร ใส่ URL |
| `FORM_ENDPOINT` | (ไม่บังคับ) สร้างฟอร์มฟรีที่ formspree.io เก็บอีเมลลีด |
| `PIXEL_ID`/`GA_ID` | (ไม่บังคับ) ติดตามโฆษณา/ยอดขาย |

2. (ไม่บังคับ) ซื้อโดเมน .com/.in.th ประมาณ ฿400/ปี แล้วชี้เข้า
