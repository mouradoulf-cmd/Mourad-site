# Avatar Cash TH — คู่มือเปิดขาย (Launch Kit)

## 1) ตั้งค่า 4 อย่างก่อนเปิดขาย (`assets/js/main.js` บรรทัดบนสุด)
| ค่า | ใส่อะไร |
|---|---|
| `LINE_OA` | LINE Official Account ของคุณ (สมัครฟรีที่ LINE OA) เช่น `@avatarcash` |
| `PROMPTPAY` | เบอร์/เลขพร้อมเพย์รับเงิน |
| `ACCOUNT_NAME` | ชื่อบัญชี |
| `MEMBER_CODE` | รหัสเข้า `members.html` (เปลี่ยนเป็นของคุณ) |

> ⚠️ รหัสใน `members.html` เป็นการป้องกันแบบเบาๆ (ฝั่งเบราว์เซอร์) คนเทคนิคเปิดดูซอร์สได้ ถ้าจะขายจริงจัง ให้ย้ายเนื้อหาไป Payhip / Gumroad / Teachable / กลุ่ม Facebook ปิด หรือใส่เนื้อหาเป็นไฟล์ PDF ส่งทาง LINE

## 2) เผยแพร่เว็บฟรี
Cloudflare Pages / Netlify / GitHub Pages — ลากโฟลเดอร์ `avatar-cash-th/` ขึ้นได้เลย (ไม่มี build step)

## 3) ลำดับเปิดขายใน 7 วัน
1. วันที่ 1: ตั้งค่า LINE OA + เผยแพร่เว็บ + ทดสอบสมัครด้วยตัวเอง 1 ครั้ง
2. วันที่ 2: สร้างอวตาร *ของคอร์สเอง* (ใช้ตามโมดูล 1–2) ให้เป็นหน้าตาแบรนด์
3. วันที่ 3–7: โพสต์ TikTok/Reels วันละ 2 คลิป ใส่ลิงก์เว็บ/LINE ในโปรไฟล์
4. ทุกวัน: ตอบคอมเมนต์/แชททุกอัน แล้วปิดการขายใน LINE

## 7) ตัวเลขเป้าหมายคร่าวๆ (ตัวอย่างคำนวณ ไม่ใช่การรับประกัน)
- แพ็กตลอดชีพ ฿4,990 × 10 คน = ฿49,900
- รายเดือน ฿990 × 30 คน = ฿29,700/เดือน
- ต้นทุน: โดเมน (~฿400/ปี) + เครื่องมือ AI (฿0–1,500/เดือน) + เวลา

## 8) ข้อควรระวังทางกฎหมาย/จริยธรรม
- ห้ามโฆษณาเกินจริง ห้ามใส่รีวิว/รายได้ปลอม — ใช้ผลลัพธ์จริงของคุณเท่านั้น
- ติดป้าย "สร้างด้วย AI" ตามนโยบายแพลตฟอร์ม
- ไม่ใช้หน้า/เสียงของคนจริงโดยไม่ได้รับอนุญาต
- หากรับเงินเป็นกิจจะลักษณะ ปรึกษานักบัญชีเรื่องภาษี/จดทะเบียน
