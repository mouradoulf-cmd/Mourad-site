# Noir — hair studio (demo template)

Plain HTML/CSS/JS, no build step. Open `index.html`.

- `assets/css/style.css` — design system and all sections
- `assets/js/i18n.js` — FR / TH dictionaries (English is in the HTML)
- `assets/js/main.js` — interactions (reveals, tabs, lightbox, reviews, booking)
- `assets/fonts/` — Bodoni Moda + Manrope, variable woff2 (SIL Open Font License)
- `assets/img/` — photos, each as `.webp` + `.jpg` fallback

## Adapting it for a client

Replace the studio name, address, hours (`HOURS` in `main.js` and the
table in the contact section), phone / WhatsApp number (`WA` in `main.js`
and the `tel:`/`wa.me` links), prices, team names and reviews — they are
demo content. Swap the photos in `assets/img/` keeping the same file
names, or update the `<picture>` sources.
